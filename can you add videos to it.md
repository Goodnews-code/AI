## Day 1: TypeScript basics

Learn types, interfaces, type aliases, unions, and function typing.

Watch:

- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)
- Search YouTube for a beginner TypeScript crash course that covers variables, functions, arrays, and objects.

Practice:

- Convert 5 JavaScript functions to TypeScript.
- Type a user object and a product object.
- Type arrays and function return values.


## Day 2: TypeScript in practice

Focus on generics, narrowing, optional properties, and utility types.

Watch:

- A TypeScript beginner-to-advanced crash course on YouTube.
- A video specifically on TypeScript generics and unions.

Practice:

- Build a typed `Todo` model.
- Write a function that accepts `string | number`.
- Add types to an existing mini project.


## Day 3: React fundamentals

Learn components, JSX, props, state, and event handling.

Watch:

- [React Learn](https://react.dev/learn)
- A beginner React course that explains components, props, and state.
- A React hooks intro video.

Practice:

- Build a counter.
- Build a profile card.
- Pass props from parent to child.


## Day 4: React hooks

Study `useState`, `useEffect`, and data fetching.

Watch:

- A React `useState` and `useEffect` tutorial.
- A video showing data fetching in React with hooks.

Practice:

- Build a todo list.
- Fetch data from an API.
- Add loading and error states.


## Day 5: React + TypeScript

Combine both and type your props, state, and event handlers.

Watch:

- A React + TypeScript crash course.
